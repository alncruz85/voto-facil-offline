## 🔒 3. Declaração de Segurança de Dados (Play Console Data Safety)

No formulário obrigatório de **Segurança dos Dados (Data Safety)** do Google Play Console:

| Pergunta no Console                                      | Resposta                                              |
| :------------------------------------------------------- | :---------------------------------------------------- |
| **O aplicativo coleta ou compartilha dados do usuário?** | **NÃO**                                               |
| **Os dados são enviados para servidores externos?**      | **NÃO**                                               |
| **O app permite que o usuário exclua os dados?**         | **SIM** (via botão nativo "Limpar dados do aparelho") |
